Website for [siz4u.de](https://siz4u.de), built with [Vite](https://vite.dev) and React.

## Scripts

* `yarn start`: dev server on http://localhost:5173
* `yarn test`: runs the tests with Vitest
* `yarn build`: type checks and builds the site into `build/`
* `yarn preview`: serves the built site locally
* `yarn deploy`: builds and publishes `build/` to the `gh-pages` branch, which GitHub Pages serves
